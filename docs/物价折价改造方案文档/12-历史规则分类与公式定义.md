# 历史规则分类与公式定义

基于 `docs/物价折价规则整理.xlsx` 的 74 条规则，逐条分类并提取公式。

---

## 一、规则族总览

从 74 条规则中提取出 **6 种规则族**：

| 规则族 | 数量 | 核心逻辑 |
|--------|------|----------|
| 2小时窗口数量上限 | 16 条 | 2小时内超过N个部位/加收项目，按N个收费 |
| 同胎次互斥封顶 | 5 条 | 同胎次多个项目同时开立，超过1个按1个收费 |
| 单项目金额封顶 | 4 条 | 单次收费不超过固定金额 |
| 固定比例递增公式 | 7 条 | 第1个100%，后续按固定比例加收 |
| 分部位单位换算 + 单肿物封顶 | 24 条 | 按部位换算面积为数量，单肿物封顶，多肿物相加 |
| 面积分段递增公式 + 同手术封顶 | 17 条 | 以15cm²为基础，超出按15%递增，同手术/单条封顶 |
| 复合项目替换加收 | 1 条 | 第2个及以上替换为加收项目 |

## 三、公式算法定义

### 公式 1：固定比例递增 `INCREMENT_PERCENT`

**适用项目：** 浅表肿物去除费、自体皮移植费

**数学表达式：**

```
totalAmount = unitPrice × (qty × rate + (1 - rate))
```

等价于：第1个按100%收费，第2个及以上按 `rate` 收费。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| unitPrice | decimal | 单价，从 fin_com_undruginfo 读取 |
| qty | int | 数量（如有双单位换算，取换算后数量） |
| rate | decimal | 递增比例。0.5 = 50%递增，0.7 = 70%递增 |

**示例：**

```
浅表肿物去除费，单价200元，数量3，rate=0.5：
totalAmount = 200 × (3 × 0.5 + 0.5) = 200 × 2 = 400元
含义：第1个200元 + 第2个100元 + 第3个100元

自体皮移植费，单价1000元，数量3，rate=0.7：
totalAmount = 1000 × (3 × 0.7 + 0.3) = 1000 × 2.4 = 2400元
含义：第1个1000元 + 第2个700元 + 第3个700元
```

---

### 公式 2：分部位单位换算 `CONVERT_QTY_BY_PART`

**适用项目：** 巨痣去除费、血管瘤去除费、脉管畸形去除费、神经纤维瘤去除费

**逻辑：** 不是数学公式，而是面积→数量的换算。

```
convertedQty = ceil(inputArea / convertBaseArea)
totalAmount = unitPrice × convertedQty
```

**不同部位的换算基数：**

| 部位 | convertBaseArea | 说明 |
|------|----------------|------|
| 头面部 | 4 cm² | 每4cm² = 1个数量 |
| 躯干部 | 144 cm² | 每144cm² = 1个数量 |
| 1%体表面积 | 1% | 每1% = 1个数量 |

**特殊规则：**
- 巨痣去除费：不分部位，1cm² = 1数量（直接面积=数量）
- 加收项目（累及重要器官）：不分部位，1个肿物 = 1数量（直接按肿物个数计）

**单肿物封顶：** 每个肿物单独计算后，与封顶价比较取小值。

```
singleLesionAmount = min(unitPrice × convertedQty, maxAmountPerLesion)
```

**多肿物汇总：**

```
totalAmount = sum(每个肿物的 singleLesionAmount)
```

**示例：**

```
血管瘤去除费(常规)，单价856元，头面部8cm²，1个肿物：
convertedQty = ceil(8 / 4) = 2
amount = 856 × 2 = 1712元
封顶2600元，1712 < 2600，最终 = 1712元

血管瘤去除费(常规)，2个肿物：头面部12cm² + 躯干部288cm²：
肿物1: ceil(12/4)=3, 856×3=2568, min(2568, 2600)=2568
肿物2: ceil(288/144)=2, 856×2=1712, min(1712, 2600)=1712
总计 = 2568 + 1712 = 4280元
```

---

### 公式 3：面积分段递增 `AREA_STEP_INCREMENT`

**适用项目：** 带蒂皮瓣转移费、游离皮瓣移植费、游离复合组织瓣移植费、带蒂复合组织瓣转移费

**数学表达式：**

```
steps = ceil(area / baseArea)      -- baseArea 默认 15cm²
amount = unitPrice × (1 + steps × stepRate)   -- stepRate 默认 0.15 (15%)
```

注意：原文写法是 `金额=单价×[1+(ceil(面积/15)×15%)]`，意思是基础价 100% + 每超出1个基础面积加收 15%。

**但需要确认：** 面积 ≤ 15cm² 时 `steps` 是 1 还是 0？

按原文理解：15cm² 以内是基础计价（steps=0 或 1 看定义），超过 15cm² 才加收。推荐理解：

```
if area <= baseArea:
    amount = unitPrice
else:
    extraSteps = ceil((area - baseArea) / baseArea)
    amount = unitPrice × (1 + extraSteps × stepRate)
```

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| unitPrice | decimal | 单价 |
| area | decimal | 面积(cm²) |
| baseArea | decimal | 基础面积，默认15 |
| stepRate | decimal | 每步加收比例，默认0.15 |

**示例：**

```
带蒂皮瓣转移费，单价2000元，面积30cm²：
extraSteps = ceil((30-15)/15) = 1
amount = 2000 × (1 + 1 × 0.15) = 2000 × 1.15 = 2300元

面积45cm²：
extraSteps = ceil((45-15)/15) = 2
amount = 2000 × (1 + 2 × 0.15) = 2000 × 1.30 = 2600元

面积15cm²（刚好基础面积）：
amount = 2000元（不加收）
```

**叠加封顶：**

- 单条封顶：每条医嘱项目有最高限价（具体金额待补充）
- 同手术封顶：同一手术所有皮瓣项目总计有最高限价（具体金额待补充）

---

### 公式 4：儿童加收 `CHILD_ITEM_PERCENT`

**适用项目：** 所有带"-儿童(加收)"后缀的项目

**数学表达式：**

```
childAmount = mainItemFinalAmount × childRate
```

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| mainItemFinalAmount | decimal | 主项目最终金额（公式+封顶后的值） |
| childRate | decimal | 加收比例，当前全部为0.30 (30%) |

**注意：** 基准取的是主项目的**最终金额**（经过公式计算和封顶之后），不是原始单价。
