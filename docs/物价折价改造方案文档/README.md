# 物价折价改造方案文档阅读顺序

## 推荐阅读顺序

建议按编号从 `01` 看到 `17`。

如果时间有限，至少先看：

1. `01-项目分析-物价折价改造.md`
2. `02-统一计价规则中心建设方案.md`
3. `03-稳定性审查与优化建议.md`
4. `08-设计缺陷与补充方案.md`
5. `10-资金风险补齐方案.md`
6. `07-开发任务清单-物价折价改造.md`

## 不同角色怎么读

## 需求和项目负责人

建议重点看：

- `01-项目分析-物价折价改造.md`
- `02-统一计价规则中心建设方案.md`
- `03-稳定性审查与优化建议.md`
- `07-开发任务清单-物价折价改造.md`

重点关注：

- 这不是单纯前端字段改造。
- 真实范围包括 HIS、自助机、公众号统一计价。
- 钱账风险主要在并发、落账失败、退费冲正、规则误发布。

## 后端开发

建议重点看：

- `02-统一计价规则中心建设方案.md`
- `03-稳定性审查与优化建议.md`
- `04-Oracle表设计草案.md`
- `05-统一计价接口设计.md`
- `08-设计缺陷与补充方案.md`
- `10-资金风险补齐方案.md`

重点关注：

- 规则条件、规则动作、公式执行器。
- `confirm -> commit/cancel` 三段式。
- `PR_LIMIT_OCCUPY` 和 `PR_LIMIT_LOCK`。
- 试算和确认必须分开。
- 所有折价必须能追溯。
- P0级缺陷：LIMIT_KEY生成规则、2小时窗口计算、规则叠加逻辑。
- 资金补齐硬约束：confirm 幂等请求指纹、跨小时滑动窗口锁、请求/占额/折价明细状态机、批量试算同批上下文、主子项目原子落账、非等价旧逻辑禁止普通计价回滚。

## 前端和 HIS 界面开发

建议重点看：

- `01-项目分析-物价折价改造.md`
- `05-统一计价接口设计.md`
- `07-开发任务清单-物价折价改造.md`

重点关注：

- 计价结果和折价原因展示。
- HIS 前端改造布局和接口调用示例代码。

## 自助机和微信公众号开发

建议重点看：

- `02-统一计价规则中心建设方案.md`
- `05-统一计价接口设计.md`
- `03-稳定性审查与优化建议.md`
- `09-HIS集成与部署方案.md`

重点关注：

- 各端不再自己写折价逻辑。
- 特殊项目必须调用统一计价服务。
- 服务异常时不能自行按普通价格收费。
- 超时降级策略和熔断机制。

## 最短阅读路径

如果只想快速抓重点，按这个顺序：

1. 看 `01`，明白业务范围。
2. 看 `02`，明白为什么要统一规则中心。
3. 看 `03`，明白怎么避免出钱账问题。
4. 看 `08`，明白当前设计有哪些缺陷需要在编码前解决。
5. 看 `10`，明白剩余资金风险的硬性补齐口径。
6. 看 `07`，明白怎么排任务。
