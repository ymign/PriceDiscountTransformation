## 三、需要一并复制的对象结构

只复制方法体不够，还需要相关对象字段，否则无法判断金额、数量、组套、退费字段的真实含义。

### 3.1 收费明细对象

请找出并复制以下对象定义或字段说明：

```text
FeeItemList
ItemList
FeeItem
UndrugItem
InpatientFeeItem
OutpatientFeeItem
```

重点字段：

| 字段类别 | 需要字段 |
|---|---|
| 项目 | 项目编码、项目名称、组套编码、子项编码、项目类别 |
| 数量 | 原始数量、折价后数量、组套数量、最小计价数量、退费数量 |
| 单价金额 | 单价、原金额、折后金额、优惠金额、最高限价、最低限价 |
| 单位 | 输入单位、计价单位、换算单位 |
| 场景 | 门诊/住院标识、收费途径、科室、执行科室、收费员 |
| 患者 | 患者号、门诊号、住院号、就诊流水号 |
| 时间 | 收费时间、确认时间、退费时间、业务发生时间 |
| 组套 | 组套标识、组号、父项目、子项目列表 |
| 折价 | 折价标识、折价比例、折价项目编码、限制数量 |

### 3.2 常数对象

需要复制读取常数的对象结构或查询方法：

```text
Constant
Const
ManagerConstant
```

重点字段：

| 字段 | 说明 |
|---|---|
| `TYPE` / `CONST_TYPE` | 常数类型，如 `Restrictingfee` |
| `CODE` | 项目编码或组套编码 |
| `NAME` | 项目名称 |
| `INPUT_CODE` | 常见为最大限制数量或扩展编码 |
| `MARK` | 组号、分组标识或其他特殊标识 |
| `SORT_ID` | 排序 |
| `VALID_STATE` | 是否有效 |
| `MEMO` | 备注 |

### 3.3 折价表对象

需要复制 `FIN_DISCOUNT_FEE` 对应实体或 SQL 查询结果字段。

重点字段：

| 字段 | 说明 |
|---|---|

| 折价比例 | 比例折价使用 |
| 最高限价 | 金额上限 |
| 最低限价 | 金额下限 |
| 生效状态 | 是否启用 |
| 适用范围 | 门诊/住院/科室/场景，如果有 |

```powershell
$root = "D:\内网源码根目录"
$patterns = @(

foreach ($p in $patterns) {
```
