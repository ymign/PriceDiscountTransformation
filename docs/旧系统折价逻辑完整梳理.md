## 一、旧系统真实调用链（三端统一）

三端（HIS 门诊/住院、自助机、微信）均编译引用同一套 `ZDWY.SpecialRule.dll`，核心折价逻辑完全一致，仅入口方法和组套展开模式不同。

```
HIS 门诊收费入口
  └─ ucDisplay.GetFeeItemList
       └─ CTMRFeeRule.GetFeeItemList(clincCode, feeArryList)
            ├─ [1] 获取挂号信息（CARD_NO/rInfo）
            ├─ [2] 医生科室补全（从员工表查询缺失科室）
            ├─ [3] 组套展开（DR/CT/普通组套 → 明细 FeeItemList[]）
            ├─ [4] 反向遍历处理单项组套去重
            ├─ [5] 遍历每条明细：
            │    ├─ db.SetRestrictingfee(itemCode, ref LimitNumber)  → 是否数量折价 + 上限数量
            │    │    SQL: "Fee.PactUnitItemRate.Restrictingfee"
            │    ├─ 若有数量折价 && 部门 != "7021"：
            │    │    └─ ConvertRestrictingfee(CARD_NO, f, ..., LimitNumber)
            │    │         └─ db.getRestrictingfee(CARD_NO, itemCode)  → 已收费次数
            │    │              SQL: "Fee.PactUnitItemRate.RestrictingfeePay2"
            │    ├─ db.SetDiscountfee(itemCode, ref DISCOUNT_RATE, ref TOPPRICE)  → 折价比例+顶价
            │    │    SQL: "Fee.PactUnitItemRate.Discountfee"
            │    └─ 若 Discount_type == "2"：
            │         └─ ConvertDiscountfee(f, DISCOUNT_RATE, TOPPRICE, ...)
            └─ [6] 删除已超限项，附加超限替换项
            
HIS 住院入口
  └─ ucInpatientConfirm.Save
       └─ ConvertRestrictingfeeZY(CARD_NO, f, ..., LimitNumber)  — 同门诊，对象类型不同

自助机入口
  └─ Patientopb.GetFeeItemList
       └─ CTMRFeeRule.GetFeeItemListnew(clincCode, feeArryList)
            ├─ 组套展开（与 GetFeeItemList 相同）
            └─ ⚠️ [5][6] 全部注释掉 → 自助机不执行数量折价和比例折价

微信入口
  └─ RegisterInfoManager.GetFeeItemList
       └─ NeusoftBussiness.MakeInvoice  — 未调用任何 ZDWY.SpecialRule 折价方法
       ⚠️ 未找到 OutpatientFeeSpecialRule.CTMRFeeRule 的源码实现（Class1.cs 为空壳）
```

## 二、数量折价（Restrictingfee）完整逻辑

### 2.1 数据来源

```sql
-- 规则配置：常数表
select code, input_code from com_dictionary where type = 'Restrictingfee'
-- code     = 项目编码
-- input_code = 最大允许收费数量（LimitNumber）

-- 运行时：查询该患者该项目的已收费次数（含2小时窗口过滤）
-- SQL index: "Fee.PactUnitItemRate.RestrictingfeePay2"
-- 入参：CARD_NO, itemCode
-- 出参：已收费次数（feetype）
```

### 2.2 计算步骤（ConvertRestrictingfee）

```
输入：CARD_NO, f(FeeItemList), LimitNumber(最大数量)
1. 查询 feetype = getRestrictingfee(CARD_NO, itemCode)
2. 计算剩余数量：Limitsum = LimitNumber - feetype
3. 分三个分支：
   ├─ Limitsum <= 0（已超限）：
   │    f.TotCost = 0, f.OwnCost = 0
   │    备注标记 "P" + 原备注
   │    加入超限集合（hsREOnlyOneItem, hsREOnlylistItem）
   ├─ Limitsum > 0 但 Limitsum < f.Item.Qty（部分超限）：
   │    f.TotCost = f.Item.Price × Limitsum
   │    f.OwnCost = f.Item.Price × Limitsum
   │    f.Item.Qty = Limitsum
   │    备注标记 "N" + 原备注
   │    加入正常收费集合（hsNOREOnlyOneItem）
   └─ Limitsum >= f.Item.Qty（未超限）：
        不修改金额和数量
        加入正常收费集合（hsNOREOnlyOneItem）
```

### 2.3 组套数量折价（ConvertRestrictingfeeCharge）

在门诊划价时，若主项为组套，需先拆开组套明细，对每条明细执行数量折价，再将费用累计回主项：

```
对每条组套明细 m：
  LimitNumber_m = getRestrictingfee(CARD_NO, m.itemCode)
  执行与明细折价相同的三分支逻辑
  sumPricecot += m.TotCost
最终：f.TotCost = sumPricecot
```

### 2.4 住院分支（ConvertRestrictingfeeZY）

逻辑与 `ConvertRestrictingfee` 完全一致，仅对象类型从 `Outpatient.FeeItemList` 改为 `Inpatient.FeeItemList`。

## 三、2小时窗口查询（getRestrictingfee）

```
SQL index: "Fee.PactUnitItemRate.RestrictingfeePay2"
入参：CARD_NO（患者就诊卡号），itemCode（项目编码）
出参：
  Reader[0] → Feecode（限制项目F码）
  Reader[1] → feetype（已收费次数，含2小时窗口过滤）
```

**重要约束**：SQL 内部实现向前查 2 小时范围内的实际收费记录（从门诊/住院收费明细表），不是从专用限额占用表查。具体 SQL 语句尚未提取（需从 HIS 配置文件获取 SQL index 对应的完整 SQL）。

### 组套分组查询（getRestrictingfeeZT）

```
SQL index: "Fee.PactUnitItemRate.RestrictingfeePayZT"
入参：CARD_NO，itemCode，GroupNumber（来自 RestrictingfeeZT 常数的 mark 字段）
出参：同 getRestrictingfee
用途：同一分组内项目互斥，组内已有任意项目收费则其他项目超限
```

## 四、比例折价（Discountfee）完整逻辑

### 4.1 数据来源

```sql
-- FIN_DISCOUNT_FEE 表
select discount_rate, topprice, discount_type from FIN_DISCOUNT_FEE
where item_code = ? and valid_state = '1'
-- discount_rate  = 折价比例（如 0.5 = 第2个以后按50%收）
-- topprice       = 最高限价（单次收费不超过此金额）
-- discount_type  = "1" 无折价，"2" 有折价
```

### 4.2 计算公式（ConvertDiscountfee）

```
输入：f(FeeItemList), DISCOUNT_RATE, TOPPRICE
公式：总费用 = 单价 × (数量 × DISCOUNT_RATE + (1 - DISCOUNT_RATE))
      等价：第1个按全价，第2个及以后按 DISCOUNT_RATE 比例收
示例：单价=100, 数量=3, rate=0.5 → 100×(3×0.5+0.5) = 200

封顶：if TOPPRICE > 0: 总费用 = min(总费用, TOPPRICE)

赋值：f.TotCost = 总费用，f.OwnCost = 总费用
```

### 4.3 住院分支（ConvertDiscountfeeZY）

逻辑与门诊完全一致，对象类型不同。

## 五、组套常数类型说明

| 常数类型 | 含义 | 关键字段 |
|---------|------|---------|
| `Restrictingfee` | 单项目数量上限 | code=项目编码，input_code=最大数量 |
| `Astrictpackagefee` | 组套内非折价豁免项目 | code=组套编码，name=豁免子项 |
| `RestrictingfeeZT` | 组套分组互斥折价 | code=项目编码，mark=组号（同组互斥） |
| `RestrictingfeeCP` | 床旁加收项目 | code=组套编码 |
| `RestrictingfeeTX1` | 胎心监护折价 | code=组套编码（计划并入 RestrictingfeeZT） |
