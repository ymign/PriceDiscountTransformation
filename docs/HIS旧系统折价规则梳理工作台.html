      04 / RULE LOGIC

      折价规则算法

      把硬编码逻辑拆成可迁移的规则语义，逐项对应新规则中心的条件和动作。

      数量限制折价 Restrictingfee

      命中项目常数后，查询患者历史收费次数，计算剩余额度。额度不足时只把超出部分归零，不拒单。

      feetype = getRestrictingfee(cardNo, itemCode) Limitsum = LimitNumber - feetype - currentBatchQty if Limitsum <= 0: finalQty = 0 amount = 0 elif Limitsum < qty: finalQty = Limitsum amount = unitPrice * Limitsum else: finalQty = qty amount = unitPrice * qty
      • 门诊：`ConvertRestrictingfee`。
      • 住院：`ConvertRestrictingfeeZY`。
      • 组套：`ConvertRestrictingfeeCharge` 展开子项后累计。

      比例折价 FIN_DISCOUNT_FEE

      第 1 个全价，第 2 个及以后按 `discount_rate` 比例收费；`topprice` 是最高价。

      amount = unitPrice + (unitPrice * discountRate) * (qty - 1) if TOPPRICE > 0 and amount > TOPPRICE: amount = TOPPRICE FT.TotCost = amount FT.OwnCost = amount
      • `discount_type == "2"` 时执行。
      • 旧表没有最低限价字段。
      • 迁移为公式动作 + 金额上限动作。

      分组与特殊常数 COM_DICTIONARY

      旧系统通过多个常数类型扩展互斥、床旁、胎心和组套豁免行为。

      Astrictpackagefee -> 组套豁免 RestrictingfeeZT -> 分组互斥 RestrictingfeeCP -> 床旁项目限制 RestrictingfeeTX1 -> 胎心项目限制
      • `RestrictingfeeZT` 需要确认组号来源。
      • `Astrictpackagefee` 迁移时不要误建折价规则。
      • 同批次互斥要用批量上下文处理。
