📋 总体评估

项目概况：本次审计范围是 D:\ai\vscode\functionmodule\2026\05\20260507物价折价改造\src，包含 .NET 6 Web API、Application、Domain、Infrastructure 四层。当前文件系统中的源码已经完成一轮明显整改：PricingAppService 变成薄门面，规则发布拆出 use case/guard，API Key 鉴权和发布能力门禁已落地，表达式公式和规则运行快照也已引入。

主要风险：最需要先处理的是发布风险和资金链路 fail-fast 问题：项目仍以 net6.0 为目标并压制 NETSDK1138，漏洞扫描显示 API 存在高危传递依赖；confirm 幂等响应在 ResponseJson 缺失时仍会用折价明细重建，和“首次响应必须原样重放”的资金语义不一致。

亮点：构建通过且 305 个测试通过；API 控制器基本都有授权策略；金额使用 decimal；规则引擎采用条件 evaluator + 动作 executor；限额锁使用 Oracle SELECT FOR UPDATE 模式；发布流程已有审批、冲突检测、动作参数校验、测试用例门禁和能力可表达性门禁。

优先修复：先升级到受支持运行时并修补漏洞依赖，然后修复幂等快照重建和表达式公式静默跳过，再补启动期认证配置校验、取消令牌贯通、Oracle 并发集成测试，最后继续拆分 PricingUseCaseBase 和规则快照批量加载。

总评：B 级，方向正确且已经不是简单 CRUD，但距离稳定上线还差“发布安全、真实数据库并发证明、资金链路 fail-fast、结构复杂度收口”这几块硬验证。
